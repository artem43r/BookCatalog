# Каталог книг

Стартовый каркас сквозного проекта на C++ и Qt Widgets.

## Текущий этап

- главное окно `QMainWindow`;
- меню «Файл», «Правка», «Справка»;
- панель инструментов и строка состояния;
- адаптивная форма сведений о книге на основе `QFormLayout`;
- действия-заготовки для очистки формы, поиска и сохранения.

Работа с моделью данных, добавление/удаление записей, SQLite и экспорт будут добавлены постепенно на следующих этапах.

## Сборка

1. Откройте `BookCatalog.pro` в Qt Creator.
2. Выберите установленный комплект Qt с компилятором.
3. Выполните Build и Run.

Проект использует qmake и модуль Qt Widgets.
