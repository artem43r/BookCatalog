# Архитектура приложения

- main.cpp — точка входа приложения.
- mainwindow.h — объявление главного окна.
- mainwindow.cpp — реализация интерфейса.
- BookCatalog.pro — конфигурация проекта Qt.
- docs/project-topic.md — форма выбора темы.

На первом этапе реализуется главное окно,
меню, панель инструментов и форма ввода книги.

На следующих этапах будут добавлены модель данных,
таблица книг и слой хранения.
