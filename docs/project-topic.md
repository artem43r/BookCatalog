## Краткое описание

Каталог книг — кроссплатформенное настольное приложение на Qt Widgets для ведения личной библиотеки. Пользователь сможет добавлять, просматривать, редактировать и удалять книги, указывая название, автора, жанр и рейтинг. Для поиска нужных записей будут доступны поиск и фильтрация по жанру. Данные планируется хранить в SQLite с возможностью импорта и экспорта каталога в JSON или XML.

## Основные сущности

- Книга: идентификатор, название, автор, жанр, рейтинг.

## Предполагаемые функции

- Добавление, просмотр, редактирование и удаление книг.
- Поиск и фильтрация по жанру.
- Хранение данных в SQLite.
- Импорт и экспорт данных.
- Автосохранение, валидация и логирование действий.
