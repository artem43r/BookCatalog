# Требования проекта

Проект: Каталог книг.

Основная сущность — книга:
- название;
- автор;
- жанр;
- рейтинг.

Основные функции:
- добавление и редактирование книг;
- удаление записей;
- поиск и фильтрация по жанру;
- хранение данных;
- экспорт и импорт.

На первом этапе создаётся каркас интерфейса.
Модель данных и хранение будут добавлены позднее.
