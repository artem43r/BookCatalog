# Проверка первого этапа

1. Приложение запускается без ошибок.
2. Главное окно отображается корректно.
3. Окно можно растягивать и уменьшать.
4. Меню и панель инструментов доступны.
5. Поля формы книги отображаются корректно.
6. Кнопка очистки сбрасывает форму.
7. Строка состояния отображается внизу окна.

Результаты проверок фиксируются по факту выполнения.
